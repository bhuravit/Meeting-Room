# ระบบจองห้องประชุม

หน้าเว็บหน้าเดียว (`index.html`) สำหรับจองห้องประชุม 2 อาคาร มีตารางรายวัน แบบฟอร์มจอง ตรวจเวลาซ้ำ ขั้นตอนอนุมัติ และหน้าผู้ดูแล

## ฟีเจอร์

- ตารางรายวัน 07:00–21:00 ช่วงละ 30 นาที แยกตามอาคารและห้อง คลิกช่องว่างเพื่อเลือกเวลา (เวลาสิ้นสุดตั้งไว้เบื้องต้น +1 ชั่วโมง)
- คลิกบล็อกการจองเพื่อดูรายละเอียด สีของบล็อกแยกตามหน่วยงาน (7 ฝ่าย และ 6 สาขาวิชา)
- แบบฟอร์มจอง: หัวข้อ รายละเอียด จำนวนผู้เข้าร่วม อาหารเครื่องดื่ม อุปกรณ์ (PC, Notebook, LCD Projector, เครื่องฉายภาพ 3 มิติ, ระบบเสียง, Online)
- ตรวจเวลาซ้ำในห้องเดียวกัน และตรวจจำนวนคนไม่ให้เกินที่นั่ง
- หน้าผู้ดูแล (`#admin`): อนุมัติ ไม่อนุมัติ ยกเลิก และเพิ่ม ลบ แก้ไขอาคาร ห้อง จำนวนที่นั่ง
- รองรับโหมดสว่างและมืด ใช้งานบนมือถือได้

## การทำงานของข้อมูล

หน้านี้สร้างให้ทำงานเป็น Artifact บน claude.ai และใช้ระบบข้อมูลและผู้ใช้ของ Claude ผ่าน `window.claude` (capability `db` และ `user`)

- เมื่อเปิดภายใน Artifact: ล็อกอินด้วยบัญชี Claude ที่ได้รับสิทธิ์ และบันทึกข้อมูลร่วมกันได้
- เมื่อเปิดไฟล์นี้นอก claude.ai (เช่น GitHub Pages): ไม่มี `window.claude` หน้าจะเข้าสู่หน้าลอคอิน และใช้ได้เฉพาะ "โหมดทดลอง" ที่ไม่บันทึกข้อมูล

ถ้าต้องการใช้งานจริงนอก claude.ai ต้องเปลี่ยนชั้นข้อมูลและการยืนยันตัวตนเป็นของตัวเอง (ฐานข้อมูลและระบบล็อกอินจริง) ส่วนหน้าตาและตรรกะของตารางนำไปใช้ต่อได้

## โครงสร้างข้อมูล (collections)

| ที่เก็บ | เนื้อหา | สิทธิ์เขียน |
|---|---|---|
| `bookings` | คำขอจอง: อาคาร ห้อง วันที่ ช่วงเวลา หัวข้อ หน่วยงาน ผู้จอง อุปกรณ์ ฯลฯ | ผู้ใช้ที่ล็อกอิน |
| `decisions` | ผลอนุมัติของแต่ละคำขอ (`approved`, `rejected`, `cancelled`) | ผู้ดูแลเท่านั้น |
| `config/venues` | รายชื่ออาคารและห้อง | ผู้ดูแลเท่านั้น |

คำขอที่ยังไม่มีรายการใน `decisions` ถือว่า "รอการอนุมัติ"

## ปรับแต่ง

ค่าเริ่มต้นอยู่ต้นสคริปต์ใน `index.html`

- `DEFAULT_B`: อาคารและห้อง (ผู้ดูแลแก้ไขจากหน้าผู้ดูแลได้)
- `UNITS`: รายชื่อหน่วยงานและสีประจำหน่วย
- `BCOL`: สีประจำอาคาร
- `N`: จำนวนช่วงเวลา 30 นาที เริ่มที่ 07:00 (ค่าเดิม 28 ช่วง สิ้นสุด 21:00)
